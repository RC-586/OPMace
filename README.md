# OPMace

The Mace is a powerful weapon on its own—****but what if it were a server-wide unique artifact?****

****OPMace restricts the crafting of the Mace to a single player per server, instantly turning it into an overpowered, legendary item.****

## Details

When the Mace is forged for the first time, a server-wide announcement broadcast is triggered, and further crafting is permanently locked. This legendary weapon comes pre-enchanted with **illegal/overpowered enchantment levels** and is completely **unbreakable**.

**Default Enchantments:**
- **Density VI** *(Increased fall attack damage)*
- **Breach IV** *(Penetrates 60% of target armor)*
- **Wind Burst II** *(Launches the attacker upwards on hit for chaining combos)*
- **Unbreakable** *(Infinite durability)*

## Technical Requirements

- **Minecraft Version:** `1.21+`
- **Server Software:** **Paper** or any Paper-based fork (Purpur, Folia, etc.)
- **Note:** Standalone Spigot is **not** supported due to Paper API dependencies.
